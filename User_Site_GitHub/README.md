# كتبي — الكتب المدرسية العراقية

مكتبة الكتب المدرسية للمتوسطة والإعدادية العلمية وفق منهج وزارة التربية العراقية.

## هيكل الملفات

```
schoolweb/
├── index.html          ← الصفحة الرئيسية
├── data.json           ← بيانات الكتب وروابط PDF
├── css/
│   └── style.css       ← نظام التصميم الكامل
├── js/
│   ├── data.js         ← البيانات المُحوَّلة
│   └── app.js          ← منطق التطبيق
└── pdf/                ← ملفات الكتب بصيغة PDF لجميع المراحل
```

## تشغيل الموقع

### الطريقة 1 — مباشرة (بدون سيرفر)
افتح `index.html` مباشرة في المتصفح. يعمل بدون سيرفر لأن البيانات مدمجة في `js/data.js` والكتب متوفرة محلياً في مجلد `pdf/`.

### الطريقة 2 — سيرفر محلي (Live Server أو Python)
افتح المجلد عبر VS Code Live Server أو أي سيرفر محلي.

## كيفية إضافة ملفات الـ PDF للكتب

الموقع يدعم طريقتين مريحتين لإضافة ملفات الـ PDF:

### الطريقة 1 — من داخل الموقع مباشرة (واجهة تفاعلية):
1. افتح صفحة الصف الدراسي واضغط على زر `➕ إضافة PDF` الموجود بجانب أي كتاب أو جزء.
2. اختر ملف الـ PDF من حاسوبك (يُحفظ في المتصفح ويعمل فوراً للقراءة والتحميل)، أو اكتب مسار/رابط الملف.
3. يمكنك تعديل أو حذف الـ PDF في أي وقت عبر زر `⚙️ تعديل`.
4. يمكنك الضغط على `📥 تصدير data.json` في رأس الصفحة لحفظ وتصدير ملف البيانات المحدّث.

### الطريقة 2 — يدوياً عبر مجلد `pdf/`:
1. ضع ملف الـ PDF الحقيقي داخل مجلد `pdf/`.
2. سمّ الملف بالاسم المقترح (مثل `g7-arabic-p1.pdf` أو راجع [README.txt](file:///c:/Users/ahmed/Desktop/schoolweb/pdf/README.txt)).
3. شغّل سكريبت `scratch/sync_pdf_folder.ps1` ليقوم بالربط التلقائي في `data.json` و `js/data.js`.

## النشر (Deployment)

### GitHub Pages (مجاني)
1. أنشئ مستودعًا على GitHub.
2. ارفع الملفات.
3. فعّل GitHub Pages من الإعدادات.

### Netlify / Vercel (drag & drop)
اسحب مجلد `schoolweb` كاملًا إلى netlify.com أو vercel.com.
